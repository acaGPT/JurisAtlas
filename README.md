# JurisAtlas

《法理学》课程地图与文献库：四十六章与全部阅读文献的可检索索引

## 在线地址

- 站点：<https://acagpt.github.io/JurisAtlas/>
- 仓库：<https://github.com/acaGPT/JurisAtlas>

## 发布方式

本仓库的 `gh-pages` 分支（站点根目录）即为站点根目录，由 GitHub Pages 直接发布：

- 站点为**纯静态**时，根目录含 `.nojekyll`（关闭 Jekyll，保留 `_` 前缀资源）；
- 站点为 **Markdown** 时，根目录含 `_config.yml`（Jekyll 渲染，**不含** `.nojekyll`）。

更新内容后提交并推送即可触发重新构建，通常 30–90 秒生效，CDN 缓存约 10 分钟。
